# Kadre — генерация кадров для агента

Система для **Hermes Agent** и **Grok Bot**. Не веб-морда. Агент принимает запрос человека и вызывает план/генерацию.

## Что вызывать

```bash
python scripts/kadre.py plan "запрос"
python scripts/kadre.py generate "запрос" --out .kadre-out/frame.jpg
python scripts/kadre.py generate "запрос" --ref /path/to.jpg --out .kadre-out/frame.jpg
```

Hermes: провайдер `nanogpt-cyber` на каждый `image_generate`. Grok Bot: те же команды как tools (см. `grok/TOOLS.json`).

## Правила (с тестов, не нарушать)

1. **Не монтировать фото.** Никаких склеек лиц и OpenCV.
2. **Сначала `plan`, потом generate** — если сомневаешься в модели.
3. **XL** (`cyberrealistic-xl`) — образ и аксессуары: Лара, Харли, Клеопатра, кошка, ведьма, 50+.
4. **Pony** (`cyberrealistic-pony-v9`) — акт, cum, писсинг, куни, наездница. Барби/кукла (XL = силикон).
5. **i2i не меняет позу.** Референс стоя → все кадры стоя. Новая поза = txt2img без `--ref`.
6. **i2i правки того же кадра** — только мелочь (убрать объект). Strength 0.28–0.40. Только `imageDataUrl` на `/api/v1/images/generations`.
7. **Акт + референс лица** не склеиваются. Выбирай акт (Pony txt2img) или лицо (XL i2i).
8. **Действие в начале промпта** — cum/piss/sex. Планировщик делает это сам, не выкидывай его промпт.
9. Всегда 21+. Не усиливай «молодость». Для 50+ не переключай на Pony.
10. Один кадр за вызов. Цена ≈ $0.0051.
